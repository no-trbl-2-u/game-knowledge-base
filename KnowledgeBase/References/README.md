# References — outside design knowledge

`type: design_reference` OKF records converting **external** design craft —
published guides, designer interviews, GDC talks, postmortems, community
wisdom — into source-backed form. Unlike `games/` (evidence about specific
games) and `patterns/` (synthesis across corpus games), this section holds
knowledge about **how to design**, imported from outside the corpus.

Contract: `KnowledgeBase/BoardGames/OKF_SPEC.md` (§ Design references).
Claims sourced only from search excerpts are marked `Confidence: low` and
queued in each doc's Open questions for a later fetch-and-regrade pass.
