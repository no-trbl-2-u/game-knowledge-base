## Summary

- 360 deterministic atomic card records generated from the structured CC BY 4.0 dataset snapshot.
- Ordering is case-insensitive card name, then source identifier.
- Records include source identifier, character/color, rarity, type, scalar energy cost, exact dataset rules text, upgrade differences, and observed keyword/token leads.
- Status and Curse cards are included because the source defines them. Card art, images, and non-card entities are excluded.
- Machine sidecars are generated by scripts/generate-slay-the-spire-card-sidecars.mjs.

## Retrieval and comparison

The structured Hugging Face Parquet dataset outranks https://slaythespire.gg/ for this corpus because it is a versioned, machine-readable whole snapshot with stable source IDs, explicit dataset licensing, and upstream provenance. The website was not used as the extraction source; it remains a possible future corroboration lead only.

## Known gaps

- English-only snapshot.
- The source reports 360 cards while other community databases may count 361 or 374 depending on version, duplicates, or special presentation records; this corpus preserves the bounded source count rather than silently merging sources.
- This is factual reference data, not a legal determination about Mega Crit's underlying game IP.
