# Nemesis

## Summary

*Nemesis* is Adam Kwapiński's 1–5 player survival-horror board game about an awakened spaceship crew, hidden agendas, an uncertain ship, and escalating Intruder pressure. The original base game supports its standard semi-cooperative format, a fully cooperative variant, solo play, and an optional post-elimination Intruder role.
