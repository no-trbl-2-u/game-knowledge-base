# Setup

## Board and threat setup

- Claim: Use the basic board side; randomize face-down Room 2 tiles into 2-slots, Room 1 tiles into 1-slots, and one face-down exploration token per room; surplus tiles/tokens stay unseen in the box.
  Source: src-003
  Evidence: Board Setup steps 1–3.
  Confidence: high
- Claim: Randomize a hidden Coordinates card, set destination to B, lock 2/3/4 escape pods at 1–2/3–4/5 players, and secretly stack one working plus one damaged token for each engine with the top token being true state.
  Source: src-003
  Evidence: Board Setup steps 4–7.
  Confidence: high
- Claim: The base Intruder bag starts with one Blank, four Larvae, one Creeper, one Queen, three Adults, plus one Adult per player; the Intruder board starts with five eggs and three hidden random weaknesses.
  Source: src-003
  Evidence: Board Setup steps 8–9.
  Confidence: high

## Crew setup

- Claim: Help cards assign player numbers/draft order and matching hidden inventories; filter objective cards above player count, then deal one Corporate and one Personal objective secretly to each player before character draft.
  Source: src-003
  Evidence: Crew Setup steps 1–4.
  Confidence: high
- Claim: In player order, reveal two random character draft cards, keep one and return the other; take that character board, miniature, shuffled ten-card action deck, loaded starting weapon and two inactive Quest Items, and begin in the Hibernatorium.
  Source: src-003
  Evidence: Crew Setup steps 5–6 and Actions taxonomy.
  Confidence: high
- Claim: Seed a blue corpse in the Hibernatorium and put the first-player token with player 1.
  Source: src-003
  Evidence: Final Crew Setup steps.
  Confidence: high

## Practical audit note

The official sequence is roughly twenty top-level steps and has nested substeps. Sort decks/tokens and pre-bag character sets before play, but preserve hidden room, engine, coordinate and objective information.
