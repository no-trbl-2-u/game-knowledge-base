## Summary

Setup assembles the invader board, fear deck, invader deck, modular island boards, supply, and each spirit's personal board/state. First-time setup deliberately removes optional complexity.

## Rules / Mechanics

Setup is both configuration and difficulty selection. The system can be made lighter or harder before play by selecting spirit complexity, power progression, blight card, adversary, and scenario.

## Player friction

- Setup has many decks, boards, dividers, tokens, and per-spirit exceptions.
- Optional modules can tempt new groups into complexity too early.

## Praised design

- Modular setup lets the same box support tutorial, standard, and advanced play.

## Better-if opportunities

- setup/teardown: provide trays or digital checklists keyed by player count.
- onboarding: first-game script should make the recommended omissions unavoidable.

## Design implications for SomberSoft

Treat setup as a difficulty contract. The interface should prevent players from accidentally accepting rules burden they do not understand.
