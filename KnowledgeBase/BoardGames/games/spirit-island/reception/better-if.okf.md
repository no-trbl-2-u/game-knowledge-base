## Summary

The strongest better-if axis is not that *Spirit Island* lacks depth. It has abundance. The improvement problem is transmission: teaching, pacing, perceived variety, and closing the game before solved states decay into administration.

## Player friction

### onboarding
- Better if the base game had an even stronger guided first play, like a scripted first round and curated invader order.

### setup/teardown
- Better if setup burden were reduced with player-count trays/checklists and optional-module gates.

### rules ambiguity
- Better if high-frequency edge cases were embedded into player aids or a searchable official rules oracle.

### turn pacing
- Better if simultaneous planning had timerless coordination aids: threat priorities, intent markers, and negotiation prompts.

### downtime
- Better if high-player-count play constrained discussion with role-based responsibilities or per-spirit suggested planning lanes.

### randomness
- Better if base-box fear/blight variation had more cards or modular uncertainty without expansion dependency.

### strategic depth
- Better if late-game solved states auto-compressed into decisive resolutions.

### scoring/endgame
- Better if invader-deck timeout and mop-up endings created climactic closure rather than abrupt or procedural finish.

### solo/co-op automation
- Better if solo mode offered balancing affordances for narrow spirits and a two-hand assistant to reduce cognitive load.

### accessibility
- Better if text-heavy cards and complex state had icon summaries, digital hover glossary, or color/shape redundancy.

## Praised design

These better-if items should not erase the core: asymmetric identities, visible enemy automation, fear-based victory, and rich cooperation are the crown jewels.

## Better-if opportunities

Top opportunities:
1. Guided onboarding and first-game scripting.
2. Endgame compression/auto-resolution for solved states.
3. High-player-count pacing and negotiation support.

## Open questions

- Did later expansions solve base-game variety complaints enough to validate modular expansion as the intended answer?
