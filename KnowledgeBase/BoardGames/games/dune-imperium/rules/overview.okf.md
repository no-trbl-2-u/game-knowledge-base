## Summary

Dune: Imperium is built on a five-phase round and a 10-point race. It welds deck-building to worker placement by making cards both destination permissions and delayed economic/combat output.

## Rules / Mechanics

- Core systems: deck-building, worker placement, hand management, faction influence tracks, conflict cards, hidden intrigue, resource conversion, and temporary/permanent agent expansion.
- Scoring vectors: faction VP, alliance VP, conflict rewards, The Spice Must Flow cards, and endgame Intrigue cards.
- Primary tension: using a card now to place an Agent means losing that card's Reveal box later that round.

## Player friction

The central card split is elegant but nonstandard. New players must be taught that a card in hand is not merely an action; it is also a future reveal value if withheld.

## Praised design

The game compresses a large strategic map into a small number of consequential turns. It makes timing, not action volume, the chief contest.

## Better-if opportunities

- onboarding: teach the card split with a scripted first round before exposing the full board.
- rules ambiguity: emphasize that card text can override normal rules and that the back-cover/icon guide is part of the operating system.
