## Summary

Terraforming Mars asks corporations to develop projects while collectively pushing Mars toward habitability. The game index and official product page identify the base game as a 2016 FryxGames release.

## Source-backed facts

- Claim: The source packet covers the English base game rather than an expansion.
  Source: src-001, src-002
  Evidence: FryxGames labels the product “base game,” and the retrieved document is the official Terraforming Mars rulebook rather than an expansion rulebook.
  Confidence: high

- Claim: The shared objective is to raise temperature, oxygen, and ocean coverage.
  Source: src-002
  Evidence: Rulebook pp. 1–2 name the three global parameters and frame them as the terraforming objective.
  Confidence: high

## Rules / Mechanics

Each corporation receives starting resources and project cards. The project tableau is the durable engine: cards can provide production, immediate effects, ongoing effects, or points, while map tiles make the global state visible.
